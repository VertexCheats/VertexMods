Recommended launcher

Use the Modrinth App

It's the cleanest way to manage Fabric, your Minecraft profiles, and your mods folder in one place. Vertex mods aren't listed in Modrinth's public directory, so you'll still grab the .jar from Vertex — but the app gives you one-click Fabric setup and an always-open mods folder to drop it into.

Manual install

Installing a mod, step by step

Four steps, about two minutes — works whether or not you're using the Modrinth App.

1 2 3 4
01

Set up Fabric

Every Vertex mod runs on Fabric. Install Fabric Loader from its official installer, then grab Fabric API from the Fabric API section — it's a required core dependency, so nothing loads without it.

Fabric

Loader + API installed

02

Download the mod

Head to Downloads, pick your Minecraft version, and grab the .jar. It saves straight to your Downloads folder — no installer, no third-party gate.

Downloading… Saved to Downloads
03

Drop it in your mods folder

Drag the .jar into .minecraft/mods — or, if you're using the Modrinth App, straight into its mods panel for the profile you're running.

04

Launch & enable

Start your Fabric profile. Once you're in-game, open the mod's settings screen and flip it on — most Vertex mods ship with everything disabled by default.
